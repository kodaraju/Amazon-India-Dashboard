 📦 Amazon India Executive Sales Dashboard

An end-to-end data analysis project that transforms raw Amazon India sales data into a high-level executive dashboard. This project focuses on turning complex business data into clear, actionable KPIs and visual insights to support strategic decision-making.

🎯 Project Objective
The goal of this project was to analyse 10,000+ sales records to understand overall business performance, identify top-earning products, and analyze geographic and operational trends across India.

📊 Key Insights Tracked
The dashboard provides real-time visibility into:
- **Financial Health:** Total Revenue, Net Profit, and Average Order Value (AOV).
- **Product Performance:** Identification of top-selling products (e.g., Laptop Backpacks, 5G Smartphones).
- **Geographic Trends:** Revenue distribution across major Indian states (Maharashtra, Karnataka, Delhi, etc.).
- **Operational Metrics:**
  - **Order Status:** Distribution of Delivered vs. Cancelled/Returned orders.
  - **Payment Methods:** Analysis of UPI, Card, and COD usage.
  - **Fulfillment:** Performance of FBA vs. Seller Flex vs. Merchant shipping.

🛠️ Tech Stack & Workflow
- **Data Cleaning:** Python (`Pandas`, `Openpyxl`) was used to clean raw data, handle missing values, and aggregate metrics.
- **Dashboarding:** Microsoft Excel (Advanced Pivot Tables, Slicers, and Native Charting).
- **Architecture:** Implemented a **Data $\rightarrow$ Logic $\rightarrow$ Presentation** structure to ensure the dashboard remains scalable and professional.

📂 Project Files
- `Amazon Sales Data India.xlsx` - The complete dataset and the final interactive dashboard.

 🚀 How to View the Dashboard
1. Download the `Amazon Sales Data India.xlsx` file.
2. Open the file in **Microsoft Excel**.
3. Navigate to the **'Dashboard'** sheet.
4. Use the **Slicers** (Filters) on the top right to filter the data by **Category** or **State** and watch the charts update instantly.
